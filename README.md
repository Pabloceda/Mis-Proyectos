🛠️ Sobre el Proyecto

Este sitio ha sido construido, utilizando un generador de sitios estáticos para garantizar velocidad, seguridad y facilidad de mantenimiento.

Motor: MkDocs (Generador de sitios estáticos en Python).

Tema: Material for MkDocs (Altamente personalizado).

Interactividad 3D: Implementación de Three.js y Vanta.js para el fondo animado (Efecto Net) en la portada.

CI/CD: Despliegue automatizado en GitHub Pages mediante GitHub Actions.

Lenguajes: Markdown, Python, HTML5, CSS3, JavaScript.

Búsqueda Inteligente: Indexado completo de contenidos con resaltado y sugerencias.

Componentes Avanzados: Uso de Admonitions, pestañas de código, diagramas Mermaid y tablas dinámicas.

Blog Integrado: Sección de noticias y tutoriales con categorización por etiquetas.
